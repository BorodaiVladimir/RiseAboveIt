# Мастерская safe zone первой локации

Утверждённое оформление мастерской внутри существующего спичечного коробка. Единственный таракан-мастер отвечает за крафт и улучшения; отдельного продавца и торговли нет.

Добавлены три предмета: рабочая подкладка на пуговицу, стенд с инструментами и полка с ёмкостями для материалов. Готовые UE 5.7 меши находятся в `Content/RiseAboveIt/Arena_Earth`: `SM_Safe_WorkSurface`, `SM_Safe_ToolRack`, `SM_Safe_PartsShelf`. Каждый имеет одну UCX-коллизию и использует существующий `M_Palette`.

`Blender` содержит редактируемые сцены с упакованными текстурами, `FBX` и `Textures` содержат исходники для импорта. `Preview` показывает проверенное оформление. Координаты и ориентиры находятся в `Workshop_Layout.json` и `Workshop_Placement.csv`.

Для расстановки откройте уровень с одним `SM_Safe_Workbench` и выполните `place_workshop.py` через Tools → Execute Python Script. Нужны Python Editor Script Plugin и Editor Scripting Utilities. Скрипт ставит три предмета и три TargetPoint относительно верстака; повторный запуск обновляет их без дублей. Сохраните уровень вручную. `SafeZone_Crafter` отмечает место существующего таракана, `SafeZone_Assembly` — место сборки, `SafeZone_PlayerApproach` — подход игрока. Второй NPC не создаётся.

В этом коммите опубликованы готовые ассеты и расстановка. Командная карта `L_Arena_Earth` сохраняет свою текущую версию; для появления предметов в ней нужно выполнить указанный скрипт. Игровое взаимодействие и логика крафта подключаются отдельно.

Проверены замкнутость моделей, коллизии, высота поверхности и проход к верстаку. Перед публикацией повторно проверены загрузка с материалами текущего main и расстановка на смещённом и повёрнутом верстаке без дублей. Отчёты находятся в `Reports`. `Authoring` содержит инструменты моделирования в прежней структуре каталогов; пути к исходной арене и NPC при пересборке нужно указать для своей машины.
