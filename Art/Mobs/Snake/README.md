# Змея Канавы — версия 4

Тело удлинено примерно на 52%, клубок поднят и состоит из трёх витков. Ориентация сегментов сохраняет брюхо снизу; хвост плавно сужается и не переворачивается при сворачивании. Голова и шея располагаются на вершине клубка. Тело спускается от них расширяющимися кольцами, хвост находится у основания. Змея подползает, сворачивается в клубок и делает из него резкие выпады с укусами. Голова стала плоской, глаза уменьшены и утоплены, пасть затемнена. Два длинных изогнутых клыка складываются к нёбу и раскрываются вместе с пастью. Отдельная тёмная палитра не меняет материалы других существ.

При смерти голова падает на бок, витки распускаются, тело переворачивается и хвост несколько раз судорожно дёргается. Последние кадры неподвижны.

В Preview/Snake_Combat_v4.mp4 показаны подползание, клубок, три укуса и смерть. Оранжевое кольцо обозначает цель. Это Blender-превью; движение по сцене добавлено для показа. В Preview/Snake_Fangs_v4.mp4 пасть и клыки видны крупно.

## Анимации

Все клипы — 30 fps, root неподвижен.

| Клип | Длительность | Назначение |
|---|---:|---|
| Idle | 4 с | Обычное ожидание, цикл |
| Move | 2 с | Подползание, цикл |
| Coil_Enter | 2 с | Сворачивание в боевую стойку |
| Coil_Idle | 3 с | Ожидание в клубке, цикл |
| Attack_Bite | 1,6 с | Один выпад и возврат в стойку |
| Attack_Combo | 3 с | Три выпада, затем возврат в стойку |
| Coil_Exit | 2 с | Выход из клубка |
| Hit | 1 с | Реакция на удар в клубке |
| Hit_Move | 1 с | Реакция в обычной позе |
| Death | 3,4 с | Смерть из клубка |
| Death_Move | 3,4 с | Смерть из обычной позы |

Последовательность: Move → Coil_Enter → Coil_Idle → Attack_Bite или Attack_Combo → Coil_Idle. Перед каждым укусом есть оттяжка головы. Пики укусов в Combo: кадры 18, 42 и 66; в Bite — 18. Это ориентиры для будущих игровых событий. AI, урон, коллизии и выбор дистанции этим пакетом не задаются.

## Перенос в UE

Готовые ассеты проверены импортом и повторной загрузкой в UE 5.7.4. Содержимое Content переносится с сохранением пути /Game/RiseAboveIt/Mobs/Snake. Пакет содержит один SkeletalMesh, один Skeleton, 11 AnimSequence, собственные текстуру и материал.

Скелет этой версии имеет 82 кости и заменяет предыдущие варианты из 32 и 50 костей. Старые анимации v1/v2 с ним не смешивать. Для ручного FBX-импорта сначала импортировать SK_Snake, затем все анимации на его Skeleton; масштаб импорта 100, Convert Scene включён, Convert Scene Unit выключен. Текстура T_Palette_Snake подключается к Base Color материала M_Snake.

Исходник Blender содержит упакованную текстуру и все действия. Инструменты генерации в Authoring относятся к подготовке моделей и анимаций. Для пересборки запустить Authoring/Snake/build_snake.py через Blender; структура Shared и Weapons рядом с папкой Snake нужна для его зависимостей. В Reports сохранены результаты проверок; SHA256.json перечисляет контрольные суммы файлов пакета.

Референсы: фотографии свёрнутых Vipera berus — https://www.nahuby.sk/obrazok_detail.php?obrazok_id=526652 ; описание защитной стойки и распрямления передней части тела при укусе Bothrops — https://www.thebhs.org/publications/the-herpetological-journal/volume-16-number-3-july-2006/451-09-defensive-behaviour-in-pit-vipers-of-the-genus-i-bothrops-i-serpentes-viperidae/file .
