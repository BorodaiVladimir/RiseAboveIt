# Rise Above It — иконки лута и таракан для диалогов

Утверждённый комплект иконок и изображений таракана-мастера.

В `PNG/Loot/512` лежат 11 основных цветных иконок. В папках `256` и `128` — варианты для меньших элементов интерфейса. Все PNG имеют настоящий альфа-канал; фон, рамки, подписи и тени на подложке в иконки не встроены.

Список сверен с текущими `BP_Loot_*` и их мешами: скотч, шестерёнка, осколок лезвия, шарик подшипника, стеклянная бусина, волос, медная проволока, конденсатор, бинт, хитин клеща и игла комара. `manifest.json` связывает файлы с блюпринтами. Названия `Chitin` и `Mosquito` в BP соответствуют `TickChitin` и `MosquitoNeedle` в арте.

В `PNG/Dialogue` два варианта принятого таракана-мастера:

- `T_UI_RoachCrafter_Bust.png` — квадрат 1024×1024 для диалогов. Нижняя часть фартука обрезана кадром; голова и оба усика сохранены целиком.
- `T_UI_RoachCrafter_Full.png` — полный персонаж 1024×1536 с отступами по краям.

Стиль сверен с `Pitch_MC2_Oranienbaum_со_спичем.pptx`, слайдами 6 и 9. В питче графитовые панели `#0C0D0B`/`#161815`, светлый текст `#E8E6DE` и лаймовый акцент `#B5F23D`; предметы на слайде лута остаются цветными low-poly моделями. Иконки сделаны из тех же моделей с их палитрой и контуром. Таракан взят из принятой исправленной модели, без изменения внешности.

`PNG/Loot/Tintable512` содержит дополнительные одноцветные силуэты с заливкой `#E8E6DE`. Их можно использовать на тёмных панелях, где тёмные детали цветного предмета теряют контраст. Для точной окраски в лаймовый используйте альфа-канал как маску; обычный цветовой tint перемножается с исходной светлой заливкой.

`Preview/Loot_Overview.png` — общий просмотр с подписями на прозрачном фоне. Подписи есть только в превью.

## UE 5.7

В `Content/RiseAboveIt/UI` в корне репозитория подготовлены 24 Texture2D: 11 цветных иконок, 11 силуэтов и два изображения таракана. Импорт и повторное открытие проверены в отдельном проекте. Настройки: группа UI, RGBA8 без сжатия, sRGB, без mipmaps, bilinear, clamp, Never Stream; альфа не отключена. Для другого размера иконок можно отдельно импортировать PNG из папок 256/128.

Виджеты, игровые таблицы и логика выпадения не менялись. Расположение портрета и размер иконок в настоящем интерфейсе ещё предстоит проверить в сцене.

Исходные PNG находятся в `Art/UI/LootAndDialogue/PNG`, готовые UE-текстуры в `Content/RiseAboveIt/UI`. Карта соответствия файлам и блюпринтам: `manifest.json`. Отчёты рядом подтверждают покрытие лута, прозрачность и импорт/повторную загрузку текстур.
